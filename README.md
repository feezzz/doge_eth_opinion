# doge_eth_opinion — ETH 行情分析

ETHUSDT 永续合约行情状态分析，按天归档。基于狗哥交易体系（纯技术流），当前以 **15m 价格行为分析为主**（关键位 + 盘中预案），非完整多周期系统。

## 分析框架

- **数据来源**：Binance 合约 API（ETHUSDT 永续 K线，北京时间）
- **数据口径**：仅对已收盘K线使用"收盘"表述（openTime + 15min ≤ serverTime）；形成中K线标注"形成中"并用"现报"表述
- **观察周期**：15m 为主（约 5 分钟轮询一次）；30m/1H/4H 及 MA45 加速带暂未系统纳入计算
- **核心原则**：
  - 收盘确认：盘中刺穿/冲高 ≠ 突破，一切以 K线收盘确认为准
  - 分仓止盈：到目标位平 75-80%，留小仓博延续
  - 宁可错过不可做错：假突破/假破位识别优先，位置不到不动手
- **预案规范**：
  - 关键位以**区间**表述（支撑/压力带），不追求单一精确价格
  - 预案标注止损/目标（盈亏比 < 1.5:1 标注"不追"）
  - 预案标注触发类型：收盘确认 / 盘中触发

## 关键位体系

- **箱体/中枢**：反复测试的支撑压力区间
- **双底/双顶**：生命支撑/压力位
- **套牢/出货区**：多次冲高失败形成的压力密集区
